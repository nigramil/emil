# Expense Tracker

**Автор:** Эмиль Галяутдинов

## Описание
Это простое GUI-приложение для отслеживания личных расходов. Можно добавлять записи о расходах, фильтровать их по категории и дате, а также подсчитывать сумму за текущий фильтр. Данные сохраняются в JSON-файл.

## Как использовать
1. Запустите файл `expense_tracker.py`.
2. Введите сумму, категорию и дату (в формате ГГГГ-ММ-ДД), затем нажмите "Добавить расход".
3. Для фильтрации введите нужные параметры и нажмите "Фильтровать" или "Показать все".
4. Для подсчета суммы нажмите "Подсчитать сумму за текущий фильтр".

## Примеры тестов
- Добавление расхода: сумма=50, категория=еда, дата=2024-04-01
- Фильтр по категории: "еда"
- Фильтр по дате: "2024-04-01"
